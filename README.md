# 🚀 Product AI – Sugus

> Plataforma inteligente para crear, estructurar y escalar productos digitales con AI.

---

## 🧠 Overview

**Product AI** es una herramienta diseñada para transformar ideas en productos reales mediante un flujo estructurado impulsado por inteligencia artificial.

No es solo un generador de contenido.

Es un sistema pensado para:
- Reducir la fricción entre idea → ejecución  
- Estandarizar decisiones de producto  
- Acelerar equipos de UX, Producto y Negocio  

---

## ⚙️ Core Features

- 🧩 Generación de **Product Briefs**
- 🤖 Creación automática de **PRDs con AI**
- 🧠 Sugerencias de **features inteligentes**
- 🗺️ Definición de **User Journeys**
- 📊 Dashboard con métricas de producto
- ⚡ Quick actions para iteración rápida

## 🧪 Run Locally

**Prerequisites:** Node.js (>= 18)

### 1. Install dependencies
```bash
npm install
```

### 2. Configure environment variables

Create a `.env.local` file and add:

```bash
GEMINI_API_KEY=your_api_key_here
```

### 3. Run the app

```bash
npm run dev
```
